Casino Hold'em

About Casino Hold'em

Casino Hold'em is a clean, portrait-oriented digital poker game built in Unity where the player goes head-to-head against the house dealer using standard 5-card community board rules.

The project focuses on solid C# state machine architecture, bankroll validation (preventing bets where the player cannot afford the subsequent 2x Call), smooth card-flip animations, and accurate 7-card poker hand evaluation.

Unity 2D C# Algorithms Casino / Card Game School Project
// Academic & Non-Commercial Notice Developed as a school programming exercise to implement card evaluation algorithms and UI state machines in C#. Uses virtual currency only, involves no real-money gambling, and is not publicly distributed.

What I Implemented

  • Betting Modes (Ante & Blind Call): Players can enter a custom bet amount and choose standard ANTE (deciding whether to Call 2x Ante or Fold after the flop) or BLIND CALL for an automatic all-in reveal.
  • Smart Bankroll Validation: Built-in balance check ("SMALL BALANCE FOR CALL!") ensuring players only place Ante bets they can afford to follow up on.
  • Animated Card Dealing: Sequential flip animations for hole cards, the 3-card flop, turn, river, and the dealer's hidden hand.
  • 7-Card Hand Evaluator: Automatically compares the best 5-card combination between Player and Dealer, handling wins, losses, and Split pots.
